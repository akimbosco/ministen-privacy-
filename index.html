Informativa sulla privacy – Ministen

Ultimo aggiornamento: 29/06/2026

Raccolta dei dati

Ministen non raccoglie, non trasmette e non condivide dati personali con server esterni.

Conservazione dei dati

Tutti i dati inseriti dall’utente, inclusi le risposte ai questionari e gli altri valori registrati nell’app, vengono salvati esclusivamente in locale sul dispositivo dell’utente.

Eliminazione dei dati

L’utente può eliminare autonomamente i dati salvati sul dispositivo utilizzando le apposite funzioni disponibili all’interno dell’app. Poiché i dati non vengono trasmessi né conservati su server esterni, Ministen non conserva copie dei dati eliminati dall’utente.

Esportazione

L’utente può esportare i propri dati in un file, ad esempio in formato CSV o Excel, e scegliere autonomamente se salvarlo sul dispositivo o condividerlo tramite le funzioni standard del sistema operativo. I file esportati sono gestiti direttamente dall’utente.

Tracking e analisi

Ministen non utilizza sistemi di tracciamento, strumenti di analisi dell’utilizzo o pubblicità comportamentale.
